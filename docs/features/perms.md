# Perms

`fima perms` is a command that display files and directories permissions.

## Usage

`fima perms PATHS`

## Example

```sh
# Get the perms of a file
fima perms file.txt

# Get the perms of a directory
fima perms directory

# Get the perms of both
fima perms file.txt directory
```
