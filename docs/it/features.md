# Funzionalità

FIMA ha una serie di funzionalità che puoi usare per gestire i tuoi file,
formando una cassetta degli attrezzi completa per il filesystem.

Cerca di rivolgersi il più possibile a sviluppatori, utenti esperti
e utenti quotidiani.

## Sottocomandi

FIMA viene fornito con una serie di sottocomandi, ciascuno con i suoi usi.

### Operazioni sui file

- [`ls`](subcommands/ls.md) Elenca il contenuto di una directory.
- [`tree`](subcommands/tree.md) Mostra l'albero delle directory.
- [`cp`](subcommands/cp.md) Copia file e directory.
- [`mv`](subcommands/mv.md) Sposta o rinomina file e directory.
- [`rm`](subcommands/rm.md) Rimuove file e directory (supporta i pattern glob).
- [`mk`](subcommands/mk.md) Crea file e directory.

### Cestino

- [`trash`](subcommands/trash.md) Gestisce il cestino.

### Archivi

- [`zip`](subcommands/zip.md) Crea archivi `.zip`.
- [`unzip`](subcommands/unzip.md) Estrae archivi `.zip`.

### Utility

- [`cloc`](subcommands/cloc.md) Conta le righe di codice.
- [`perms`](subcommands/perms.md) Mostra i permessi di file e directory.

## Personalizzazione e configurazione

FIMA supporta la configurazione e i temi attraverso appositi
file di configurazione e di tema.

[Scopri di più](customization-and-configuration.md)
