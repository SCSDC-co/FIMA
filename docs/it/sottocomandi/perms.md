# Perms

`fima perms` è un comando che mostra i permessi di file e directory.

## Utilizzo

`fima perms PERCORSI`

## Esempio

```sh
# Ottenere i permessi di un file
fima perms file.txt

# Ottenere i permessi di una directory
fima perms directory

# Ottenere i permessi di entrambi
fima perms file.txt directory
```
