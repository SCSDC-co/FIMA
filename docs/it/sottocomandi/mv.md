# MV

`fima mv` è un semplice comando che rinomina
o sposta un file o una directory in un'altra posizione.

## Utilizzo

`fima mv VECCHIO_PERCORSO NUOVO_PERCORSO`

## Esempi

```sh
# Spostare un file
fima mv file.txt ../file.txt

# Spostare una directory
fima mv directory ../directory

# Rinominare un file
fima mv file.txt new_name.txt

# Rinominare una directory
fima mv directory new_name
```
