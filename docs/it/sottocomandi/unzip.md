# Unzip

`fima unzip` è un semplice comando che estrae archivi `.zip`.

## Utilizzo

`fima unzip ARCHIVIO -o OUTPUT`

**Opzioni:**

- `-o, --output TEXT OBBLIGATORIO` L'archivio estratto di output

## Esempi

```sh
# Estrarre un archivio
fima unzip archive.zip -o unzipped_archive
```
