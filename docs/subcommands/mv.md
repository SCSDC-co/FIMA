# MV

`fima mv` is a simple command renames
or moves a file or a directory in another location.

## Usage

`fima mv OLD_PATH NEW_PATH`

## Examples

```sh
# Move a file
fima mv file.txt ../file.txt

# Move a directory
fima mv directory ../directory

# Rename a file
fima mv file.txt new_name.txt

# Rename a directory
fima mv directory new_name
```
